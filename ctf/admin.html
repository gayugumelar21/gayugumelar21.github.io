Buat & Publish Soal CTF

Mode Spreadsheet: Soal sekarang disimpan di Google Sheet (tab Challenges). Isi form → klik Generate → klik Salin baris → di Google Sheet, klik sel kolom id pada baris kosong berikutnya → Paste (Ctrl+V). Flag (kolom paling kanan) disimpan apa adanya dan dicek di server, tidak pernah dikirim ke browser peserta.
Dipakai untuk menyimpan status solve. Harus unik.
Mendukung Markdown sederhana: **tebal**, *miring*, `kode`, ```blok```, - list, [teks](url).
