# Dasar SEO untuk Website Portfolio

Punya website portfolio yang bagus saja tidak cukup kalau tidak ada yang menemukannya. Di sinilah **SEO (Search Engine Optimization)** berperan. Berikut dasar-dasar yang perlu kamu terapkan.

## 1. Meta Tag yang Tepat

Pastikan setiap halaman punya `title` dan `meta description` yang relevan:

```html
<title>Gayu Gumelar — Cyber Security Enthusiast</title>
<meta name="description" content="Portfolio & artikel seputar cyber security dan SEO.">
```

## 2. Struktur Konten yang Rapi

- Gunakan **satu** `<h1>` per halaman
- Susun heading secara hierarkis (h1 → h2 → h3)
- Tulis konten yang menjawab pertanyaan pembaca

## 3. Kecepatan Halaman

Google menyukai halaman yang cepat. Beberapa tips:

1. Kompres gambar (gunakan format WebP)
2. Minimalkan JavaScript yang tidak perlu
3. Manfaatkan caching browser

## 4. Mobile Friendly

Lebih dari setengah trafik berasal dari ponsel. Pastikan desain **responsif** dan teks tetap nyaman dibaca tanpa zoom.

## 5. Konten Berkala

Mesin pencari menyukai website yang **aktif**. Rutin menulis artikel (seperti yang sedang kamu baca ini) membantu meningkatkan otoritas domain.

## Penutup

SEO adalah maraton, bukan sprint. Terapkan dasar-dasar ini secara konsisten, dan website portfolio kamu akan perlahan naik di hasil pencarian. 🚀
